# 로비 SD 말랑 상호작용 및 배치 편집 개선 설계

## 의도

로비 SD가 사라지거나 저화질로 보이는 문제를 막고, 볼 당김을 고무줄이 아닌 부드러운 젤리처럼 만들며, 원근 바닥 편집을 처음 보는 사람도 이해할 수 있게 한다.

## 동작

- 로비 SD는 원본 이미지 해상도를 유지한다. 스티커 외곽선 캐시는 원본 크기에서 만들고, 볼 당김도 원본 크기 캐시를 입력으로 사용한다.
- 볼은 포인터를 즉시 복사하지 않고 감쇠 보간으로 따라간다. 놓으면 짧고 약한 오버슈트 후 정지한다.
- 바닥 편집은 `소실점`, `멀리 걷는 선`, `가까이 걷는 선`으로 표시한다. 각 선의 가운데를 끌면 높이, 양 끝을 끌면 폭을 바꾼다.
- 바닥 편집 중에는 하단 로비 메뉴를 흐리게 하고 입력을 차단하며, 편집기는 모든 로비 메뉴보다 앞에 둔다.
- 잘못되거나 화면 밖인 저장 좌표는 현재 바닥 안으로 복구한다. SD가 존재하고 표시가 켜진 캐릭터는 최소 한 명 이상 로비에 다시 나타나야 한다.
- 스토리 선택지가 실제로 존재할 때만 둥근 캡슐형 말랑 선택지 카드를 표시한다. 선택지가 없으면 관련 레이아웃과 장식도 만들지 않는다.

## 범위와 제약

- 마리나라·가챠포지 본체를 패치하지 않는 개인 확장만 수정한다.
- 기존 서버 저장 키와 캐릭터별 SD·대사·볼 위치 데이터는 유지한다.
- 외부 라이브러리나 빌드 단계는 추가하지 않는다.

## 접근 방식

- 선택: 원본 해상도 베이크 + Canvas 국소 젤리 변형. 화질과 국소 변형을 함께 유지한다.
- 제외: 얼굴 전체 CSS 확대. 빠르지만 볼을 잡는 느낌이 약하다.
- 제외: WebGL 셰이더. 확장 호환성과 유지 비용이 과도하다.
