# Gacha UI Style · 말랑 (트릭컬풍)

마리나라 엔진 **가챠 포지 1.8.13**용 개인 확장입니다. 가챠 포지 **설정 → 화면 → UI 스타일**에 여섯 번째 스타일 **말랑**을 추가하고, 켜면 게임 화면 전체를 트릭컬 리바이브 느낌으로 바꿉니다.

게임 파일과 세계에 저장된 HUD 스타일은 건드리지 않습니다. 전투 규칙 · 클릭 · 저장은 전부 가챠 포지 그대로이고, 보이는 모양만 바뀝니다. 게임의 다른 스타일(오로라 · 블룸 …)을 고르면 말랑이 꺼지고 원래 화면으로 돌아갑니다.

## 바뀌는 화면

| 화면 | 말랑에서 |
| --- | --- |
| 전체 UI | 둥근 모서리, 두꺼운 외곽선, 눌리면 내려가는 버튼, 물방울 무늬 배경, 리본 제목, 노란 "전투 시작" 버튼, Jua 글꼴 |
| 홈 | **로비**: 캐릭터 SD들이 설정한 바닥 전체를 앞뒤로 돌아다니고, 멀어지면 작아지며 걷는 방향을 봅니다. 누르면 성격에 맞는 대사를 하고, **볼을 누른 채 끌면** 놓을 때 반응합니다. [✥ 배치]에서 캐릭터 위치와 크기를 바꾸거나 **[소실점 · 바닥]**으로 소실점 1개와 서 있을 수 있는 사다리꼴의 네 모서리를 직접 옮깁니다. |
| 출석 이벤트 | 도장 찍는 출석부: 받은 날은 빨간 "출석" 도장, 오늘 칸은 통통 튀며 "오늘!" 표시, 6 · 7일차 보상은 금색 칸, 옆에서 캐릭터가 말을 겁니다. **[받기]를 누르면 바로 도장이 찍히고 받기가 끝나면 저절로 닫힙니다.** |
| 편성 | 편성 칸 위에 팀 SD가 둥실 떠 있습니다. |
| 전투 시작(브리핑) | 시작 버튼 위에 팀 SD가 한 줄로 떠 있습니다. 전투 전에는 땅에 점선 배치 칸이 보입니다. |
| 전투 | **필드 전투**: 카드 대신 아군은 왼쪽, 적은 오른쪽 땅 위에 앞줄 · 뒷줄 · 세 갈래 깊이로 섭니다. 머리 위에 이름 · HP 바, 행동할 때 상대 쪽으로 돌진, 맞으면 찌그러짐. 그림 없는 적은 속성 색 버섯 몬스터. 행동 버튼은 아래 한 줄 카드로 모입니다. |
| 결과 | 이기면 참여한 팀 SD가 폴짝폴짝 뜁니다. |
| 스토리 | 현재 화면에 실제로 등장한 캐릭터만 최대 3명까지 대화창 위에 섭니다. 퇴장·장소 이동·CG·선택지를 즉시 반영하고, SD가 없는 캐릭터는 윗부분이 잘리지 않는 초상 카드로 표시합니다. |
| 소환 · 기타 | 배너 카드·상세 패널·천장 표시·소환 버튼·결과 카드를 말랑 카드와 캡슐 버튼으로 바꿉니다. |
| 로딩 | 물방울 배경 + 통통 튀는 SD(누르면 "말랑!") + TIP 말풍선 + SD가 달리는 캡슐 진행 바. 세계 만들기 화면의 회전 문양도 마스코트로 |

## 설정 (설정 → 화면, 말랑을 켰을 때만 보임)

말랑 설정에는 **UI 설정**과 **SD 관리** 목록이 따로 표시됩니다.

- **말랑 색상**: 프리셋 5종(크림 코코아 · 딸기 우유 · 민트 초코 · 라벤더 · 밤하늘) + 색 8개(바탕 · 카드 · 글자 · 외곽선 · 강조 버튼 · 선택 표시 · 배경 1 · 배경 2) 직접 고르기, [글꼴 받기]
- **트릭컬 화면**: 전투 필드 · 편성/출격 캐릭터 · 홈 로비 · 홈 대표 카드 숨기기 · 출석 이벤트 켜기/끄기, **홈 로비에 둘 캐릭터 목록**
  - 홈의 **[✥ 배치] → [소실점 · 바닥]**: `소실` 손잡이와 `뒤L/뒤R/앞L/앞R` 손잡이로 배경 원근과 이동 가능 바닥을 맞춥니다. 이동 범위와 원근값은 세계별로 서버에 저장됩니다.
- **스토리 · 전투 이미지**: 불투명 대화창 · 스티커 초상 · 말랑 움직임 · 스토리에 SD · 전투에 SD · 로딩 화면 켜기/끄기
- **SD 캐릭터 만들기**: 이미지 연결 고르기, 프롬프트 · 네거티브 · 크기, 캐릭터별 그리기/다시/지우기/**편집**, [없는 캐릭터 전부 그리기], **[대사 만들기 (AI)] · [없는 대사만]**
  - **편집**: 캐릭터가 **바라보는 방향**(왼쪽 · 정면 · 오른쪽)을 정하면 로비에서 걷는 방향, 스토리 · 전투에서 마주 보는 방향이 맞춰집니다. 그림에서 볼을 눌러 볼 위치(최대 2곳)와 볼 크기를 정하고, 그 자리에서 미리 당겨 볼 수 있습니다. 로비 대사 3개와 볼 꼬집기 반응을 직접 고칠 수 있습니다.
  - **대사 만들기**: 이 세계의 AI 연결로, 가챠 포지에 저장된 각 캐릭터의 성격·설정을 보고 대사 3개와 꼬집기 반응 1개를 씁니다(한 번 호출로 전원).

## SD 캐릭터 만들기

- 엔진의 이미지 연결(기본값: 이 세계의 이미지 연결)로 그립니다. 그릴 때마다 연결 사용량(NovelAI는 Anlas)이 듭니다.
- 기본 프롬프트: `4::chibi, chibi only::, solo, Transparent background, 1.2::full body::, shoes, standing, looking at viewer, {appearance}`
  - `{appearance}`는 가챠 포지 캐릭터 정보의 외형 묘사, `{name}`은 이름으로 바뀝니다.
- 그림은 Marinara 갤러리에 저장되고, 어느 캐릭터의 SD인지와 대사·볼 위치·방향·키·의상별 SD는 이 확장의 서버 저장소에 기록되어 다른 기기에서도 같이 보입니다.
- SD가 없는 캐릭터는 전투 · 편성에서 초상 스티커 카드로 나오고, 홈 로비에는 나오지 않습니다.

## 성능

SD의 흰 스티커 테두리는 처음 볼 때 한 번만 그림에 구워 두고(blob 이미지), 화면에서는 필터 없이 움직입니다. 로비 · 스토리의 움직임은 시계 기준으로 이어져서 게임이 화면을 다시 그려도 처음부터 다시 시작하지 않습니다. 로딩 화면은 0.35초 넘게 걸리는 로딩에만 뜹니다.

## 다른 기기 · Tailscale에서 쓸 때

Marinara는 127.0.0.1이 아닌 곳(다른 기기, Tailscale, 프록시)에서 오는 저장 요청에 `x-marinara-csrf` 헤더가 없으면 거부합니다. 모든 저장 요청에 이 헤더를 붙이고, 빠르게 여러 값을 바꿔도 순서대로 저장해 오래된 요청이 최신 설정을 덮지 않게 했습니다. 이전 버전에서 그린 SD는 갤러리에는 있지만 목록이 저장되지 않았을 수 있는데, 세계를 열면 갤러리에서 자동으로 되찾습니다(설정의 [갤러리에서 되찾기]로 직접 할 수도 있습니다). 저장이 실패해도 이 브라우저에 보관했다가 15초마다 다시 보냅니다.

## 저장되는 곳

| 무엇 | 어디 |
| --- | --- |
| 말랑 켜기/끄기 | 이 브라우저(localStorage) |
| 색상 · 옵션 · 프롬프트 · 홈 배치 | 이 확장의 서버 저장소(기기 간 공유), 이 브라우저에도 사본 |
| SD 목록 · 볼 위치 · 캐릭터 대사 | 이 확장의 서버 저장소 `sd:<세계 ID>` |
| SD 그림 | Marinara 갤러리 |
| 둥근 글꼴 | [글꼴 받기] → Marinara 글꼴 보관함(data/fonts) |

마리나라 페이지의 보안 정책(CSP)이 외부 글꼴을 막기 때문에, 글꼴은 Marinara 자체 글꼴 기능으로 받습니다. 받기 전에는 맑은 고딕으로 보입니다.

## 설치

Marinara의 **GitHub 확장 관리자**에 이 저장소 주소를 등록하고 설치 · 실행 승인합니다(전체 페이지 접근 필요).

```text
https://github.com/lemonpie601/Gacha-UI-2
```

로컬 개발용: `node tools/install.mjs [포트]` — 같은 이름의 확장이 있으면 코드를 바꾸고 승인합니다(기본 포트 7861, 테스트 서버).

## 함께 쓰는 확장

- Gacha Story Glass(투명화)와 같이 쓸 때 **불투명 대화창**을 켜면 대화창은 말랑 상자가 됩니다. 투명 대화창을 원하면 이 옵션을 끄세요.
- Gacha Choice · Customizer처럼 설정 화면에 끼어드는 확장과 겹치지 않습니다.

## 지원 버전

Marinara Engine 2.5.1 / Gacha Forge 1.8.13에서 확인했습니다. 가챠 포지의 화면 구조가 바뀌면 일부 꾸밈이 적용되지 않을 수 있지만, 게임 동작은 바뀌지 않습니다.
